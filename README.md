## 云南政府采购网 — 站内关键词搜索工具

基于 `yngp` 分支，起始网址固定为 [http://www.yngp.com/](http://www.yngp.com/)。

### 开发模式启动

```bash
start_debug.bat

# 或直接
python server.py
# 或  
uvicorn server:app --host 127.0.0.1 --port 7100
```

浏览器打开 `http://127.0.0.1:7100`。

### 便携版（独立桌面应用）

`portable/` 目录包含打包好的应用：

```
portable/
  yngp_searcher.exe    # 主程序（独立桌面窗口）
  playwright/          # Chromium 浏览器
  start.bat            # 双击启动
```

双击 `start.bat` 或 `yngp_searcher.exe` 打开**独立桌面窗口**，无需浏览器。复制整个 `portable` 文件夹到任意 Windows 电脑即可使用，无需安装 Python 或其他依赖。

> 首次启动约需 3 秒初始化，窗口标题"云南政府采购网 — 站内关键词搜索"。

### 搜索

1. 输入关键词（多个用空格分隔），如 `教育 设备 采购`
2. 选择抓取模式（默认自动模式）
3. 点击 **搜索**

| 模式 | 说明 |
|---|---|
| 自动 | 先静态快搜，命中少时自动 JS 渲染补搜 |
| 强制 JS 渲染 | 用 headless Chromium 渲染所有页面 |
| 仅静态（最快） | 不用浏览器，直接抓 HTML |
| 归档深扫 | 全量翻页栏目列表 + 抓取所有文章正文 |

### 定时搜索任务

页面下方的 **定时搜索任务** 区域：

1. 填写任务名（可选）、关键词
2. 选搜索模式和定时方式（每天定点 / 每隔 N 小时）
3. 点击 **创建任务**

任务卡片显示：启用开关、下次运行时间、上次命中数、AI 概括按钮、删除/立即运行。

### AI 功能

搜索完成后，页面顶部出现 AI 助手区域：

| 按钮 | 功能 |
|---|---|
| **生成 AI 摘要** | 结构化概览 + 条目卡片 |
| **提问** | 就本次搜索结果内容自由提问 |

### 搜索结果

- 卡片标题为正文提取的项目名称/公告标题
- 关键词高亮，**跳转定位** 和 **所在页定位**
- AI 摘要卡片可点击打开目标页

### 重新打包

```bash
build_portable.bat
```
